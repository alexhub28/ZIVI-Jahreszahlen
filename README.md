# Graphiques ZIVI

Graphiques de données interactifs (D3.js v7, vanilla JS) pour le service civil (ZIVI). Chaque dossier est un graphique autonome : ouvrir son `index.html` dans un navigateur suffit pour le voir fonctionner (D3 est chargé depuis un CDN).

La plupart des graphiques supportent trois langues via un paramètre d'URL, par exemple `index.html?lang=fr` (`de` par défaut, `fr` et `it` disponibles).

## Liste des graphiques

- **Anzahl-Kurse** — Nombre de cours par année (barres)
- **Anzahl-Kurse bulles** — Nombre de cours par année (bulles)
- **DT nach TB** — Jours de service par domaine d'activité (barres)
- **DT nach TB pie chart** — Jours de service par domaine d'activité (camembert)
- **EiB-pro-TB** — Établissements et places d'affectation par domaine d'activité (barres)
- **EiB-pro-TB bulles** — Établissements et places d'affectation par domaine d'activité (bulles)
- **Einsatzbetriebe und Einsatzplätze** — Établissements et places d'affectation par année
- **Geleistete DT** — Jours de service effectués par année
- **Inspections bicolores** — Inspections annoncées / non annoncées (version bicolore)
- **Inspections contraste** — Inspections annoncées / non annoncées (version dégradé de couleur)
- **Kurse pro Kursart bar chart** — Nombre de cours par genre de cours (barres)
- **Kurse pro Kursart pie chart** — Nombre de cours par genre de cours (camembert)
- **Rechtsdienst** — Décisions disciplinaires par année
- **Zulassungen** — Admissions par année
