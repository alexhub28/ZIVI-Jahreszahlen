# Statistiques annuelles Office fédéral du service civil

Graphiques de données interactifs (D3.js v7, vanilla JS) pour le service civil (ZIVI). Chaque dossier est un graphique autonome : ouvrir son `index.html` dans un navigateur suffit pour le voir fonctionner (D3 est chargé depuis un CDN).

Les graphiques supportent trois langues via un paramètre d'URL, par ex. `index.html?lang=fr` (`de` par défaut, `fr` et `it` disponibles).

## Liste des graphiques

- **Anzahl-Kurse** — Nombre de cours par année (bar chart)
- **Anzahl-Kurse bulles** — Nombre de cours par année (bulles)
- **DT nach TB** — Nombre de jours de service accomplis par domaine d'activité (bar chart)
- **DT nach TB pie chart** — Nombre de jours de service accomplis par domaine d'activité (pie chart)
- **EiB-pro-TB** — Nombre d'établissements et de places d'affectation par domaine d'activité (bar chart)
- **EiB-pro-TB bulles** — Nombre d'établissements et de places d'affectation par domaine d'activité (bulles)
- **Einsatzbetriebe und Einsatzplätze** — Nombre d'établissements et de places d'affectation par année
- **Geleistete DT** — Nombre de jours de service effectués par année
- **Inspections bicolores** — Nombre d'inspections annoncées / non annoncées (version bicolore)
- **Inspections contraste** — Nombre d'nspections annoncées / non annoncées (version dégradé de couleur)
- **Kurse pro Kursart bar chart** — Nombre de cours par genre de cours (bar chart)
- **Kurse pro Kursart pie chart** — Nombre de cours par genre de cours (pie chart)
- **Rechtsdienst** — Décisions disciplinaires par année
- **Zulassungen** — Nombre d'admissions par année
