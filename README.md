# Statistiques annuelles Office fédéral du service civil

Graphiques de données interactifs (D3.js v7, vanilla JS) pour le service civil (ZIVI). Chaque dossier est un graphique autonome : ouvrir son `index.html` dans un navigateur suffit pour le voir fonctionner (D3 est chargé depuis un CDN).

**Voir les graphiques en ligne : [alexhub28.github.io/ZIVI-Jahreszahlen](https://alexhub28.github.io/ZIVI-Jahreszahlen/)**

Les graphiques supportent trois langues via un paramètre d'URL, par ex. `index.html?lang=fr` (`de` par défaut, `fr` et `it` disponibles).

## Liste des graphiques

- [**Anzahl-Kurse**](https://alexhub28.github.io/ZIVI-Jahreszahlen/Anzahl-Kurse/) — Nombre de cours par année (bar chart)
- [**Anzahl-Kurse bulles**](https://alexhub28.github.io/ZIVI-Jahreszahlen/Anzahl-Kurse%20bulles/) — Nombre de cours par année (bulles)
- [**DT nach TB**](https://alexhub28.github.io/ZIVI-Jahreszahlen/DT%20nach%20TB/) — Nombre de jours de service accomplis par domaine d'activité (bar chart)
- [**DT nach TB pie chart**](https://alexhub28.github.io/ZIVI-Jahreszahlen/DT%20nach%20TB%20pie%20chart/) — Nombre de jours de service accomplis par domaine d'activité (pie chart)
- [**EiB-pro-TB**](https://alexhub28.github.io/ZIVI-Jahreszahlen/EiB-pro-TB/) — Nombre d'établissements et de places d'affectation par domaine d'activité (bar chart)
- [**EiB-pro-TB bulles**](https://alexhub28.github.io/ZIVI-Jahreszahlen/EiB-pro-TB%20bulles/) — Nombre d'établissements et de places d'affectation par domaine d'activité (bulles)
- [**Einsatzbetriebe und Einsatzplätze**](https://alexhub28.github.io/ZIVI-Jahreszahlen/Einsatzbetriebe%20und%20Einsatzpl%C3%A4tze/) — Nombre d'établissements et de places d'affectation par année
- [**Geleistete DT**](https://alexhub28.github.io/ZIVI-Jahreszahlen/Geleistete%20DT/) — Nombre de jours de service effectués par année
- [**Inspections bicolores**](https://alexhub28.github.io/ZIVI-Jahreszahlen/Inspections%20bicolores/) — Nombre d'inspections annoncées / non annoncées (version bicolore)
- [**Inspections contraste**](https://alexhub28.github.io/ZIVI-Jahreszahlen/Inspections%20contraste/) — Nombre d'inspections annoncées / non annoncées (version dégradé de couleur)
- [**Kurse pro Kursart bar chart**](https://alexhub28.github.io/ZIVI-Jahreszahlen/Kurse%20pro%20Kursart%20bar%20chart/) — Nombre de cours par genre de cours (bar chart)
- [**Kurse pro Kursart pie chart**](https://alexhub28.github.io/ZIVI-Jahreszahlen/Kurse%20pro%20Kursart%20pie%20chart/) — Nombre de cours par genre de cours (pie chart)
- [**Rechtsdienst**](https://alexhub28.github.io/ZIVI-Jahreszahlen/Rechtsdienst/) — Décisions disciplinaires par année
- [**Zulassungen**](https://alexhub28.github.io/ZIVI-Jahreszahlen/Zulassungen/) — Nombre d'admissions par année
